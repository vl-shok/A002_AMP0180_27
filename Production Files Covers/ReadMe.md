# 📦 Enclosure Covers – Fabrication Files

This folder contains files for manufacturing the **top and bottom aluminum covers** for the A002 RF Amplifier project.

---

## 🧾 File Descriptions

| File Name                           | Description                                                                 |
|-------------------------------------|-----------------------------------------------------------------------------|
| `A002.101.00 AD BOT Cover v1.0.pdf` | Technical drawing of the **bottom cover** with thread markings (M3) — used for manufacturing with threaded holes. |
| `A002.101.00 BOT Cover v1.0.stp`    | 3D STEP model of the bottom cover – visual and machining reference.        |
| `A002.102.00 TOP Cover v1.0.stp`    | 3D STEP model of the top cover – visual and machining reference.           |
| `Reference for lazer.jpg`           | Image to be used as a guide for **laser engraving** (placement reference). |
| `Title.dxf`                         | DXF file for **laser engraving design** – use this as artwork input.       |
